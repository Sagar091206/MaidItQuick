# MaidItQuick visual system

## Brand direction

Premium, fast and dependable home help. Use a deep evergreen foundation with a high-energy lime accent and clean white type.

## Logo assets

- Square app/logo: `maiditquick-mobile/assets/branding/maiditquick-logo-square.jpeg`
- Horizontal wordmark: `maiditquick-mobile/assets/branding/maiditquick-wordmark.jpeg`
- Tagline: **Home help in minutes.**

## Color palette

| Name | Hex | Usage |
|---|---|---|
| Deep green | `#07170F` | Main app background |
| Dark green | `#0D2B1E` | Cards and dark surfaces |
| Primary green | `#22C55E` | Primary action, availability, highlights |
| Supporting green | `#16A34A` | Pressed/secondary accent |
| White | `#FFFFFF` | Primary text/logo |
| Muted mint | `#B8CABC` | Secondary text |

## Typography

- **Plus Jakarta Sans** for all customer, worker and admin interfaces.
- Use Bold/Semibold for headings and actions; Medium/Regular for body text.
- The Flutter app downloads this typeface through the `google_fonts` package when dependencies are installed.

## UI rules

- Dark evergreen background; avoid light default screens.
- Use `#22C55E` only for action, availability and key emphasis.
- Use 14–24 px rounded corners for buttons/cards.
- Keep text white or muted mint; do not use low-contrast green text on dark backgrounds.
- Use the square mark for an app icon and the horizontal wordmark for splash/login/header screens.
